# LDA-UDE-IFS Landing Page

## Overview

This repository contains the landing page website for LDA-UDE-IFS (Latent Dirichlet Allocation, Universal Differential Equations, and Iterative Function Systems), an advanced machine learning platform.

## Website Features

- **Modern Responsive Design**: Clean, professional design that works seamlessly across desktop, tablet, and mobile devices
- **Interactive Research Sections**: Dynamic content switching between different research areas (NLP, Finance, Bioinformatics, Physics)
- **Animated Hero Section**: Eye-catching floating nodes animation with gradient background
- **Contact Form**: Functional contact form with validation and user feedback
- **Accessibility**: WCAG compliant with keyboard navigation and screen reader support
- **Performance Optimized**: Fast loading with optimized animations and efficient code

## Structure

- `index.html` - Main landing page with semantic HTML structure
- `styles.css` - Comprehensive CSS with responsive design and animations
- `script.js` - Interactive JavaScript functionality and form handling

## Technology Stack

- **HTML5**: Semantic markup with accessibility features
- **CSS3**: Modern styling with Flexbox, Grid, and CSS animations
- **Vanilla JavaScript**: No dependencies, pure JavaScript for interactivity
- **External Dependencies**: 
  - Google Fonts (Inter) for typography
  - Font Awesome for icons

## Research Areas Covered

1. **Natural Language Processing**: Topic modeling, sentiment analysis, document clustering
2. **Financial Modeling**: Risk assessment, market prediction, portfolio optimization  
3. **Bioinformatics**: Gene expression analysis, protein folding prediction
4. **Computational Physics**: Quantum systems, climate modeling, particle physics

## Local Development

To run the website locally:

```bash
# Clone the repository
git clone https://github.com/siddiqmumin68-oss/LDA-UDE-IFS.git

# Navigate to the directory
cd LDA-UDE-IFS

# Start a local server (Python 3)
python3 -m http.server 8000

# Or use Node.js if you have it installed
npx serve .

# Open http://localhost:8000 in your browser
```
